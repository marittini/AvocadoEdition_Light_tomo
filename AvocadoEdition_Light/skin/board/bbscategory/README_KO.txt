말머리 BBS 게시판 (bbscategory) — 아보카도 에디션 라이트 TOMO 이식본

원본: 뀰 「[아보카도 에디션] 말머리 BBS 게시판」 (bbs_custum_category)
      https://www.postype.com/@kkyoul/post/19291007
      사도세자님 bbs_2 기반, 지비님 데코 BBS 게시판·잉님 갠꾸팁 참고
원본은 아보카도 퍼스널 + PHP 5.5 기준입니다. 이 폴더는 라이트 TOMO(PHP 8.4)에 맞게 고친 것입니다.

[설치]
- 이 폴더를 skin/board/bbscategory 에 둡니다.
- 관리자 > 게시판 관리에서 스킨을 bbscategory 로 고릅니다.
- 게시판 설정의 '분류 사용'은 꺼 두세요. 말머리가 자동으로 카테고리가 됩니다.
- 원본과 달리 bbs/write_update.php(코어)를 고치지 않습니다.
- 보호글을 쓰려면 최고관리자가 이 게시판의 글쓰기 화면을 한 번 열어 주세요(보호글 비밀번호 칸을 DB에 만듭니다).

[사용]
- 제목을 "말머리) 제목" 처럼 쓰면 말머리가 카테고리 메뉴에 글 수와 함께 나타납니다.
- 공개 범위: 전체공개 / 비밀글 / 보호글(비밀번호) / 멤버공개(로그인 회원)
- 본문은 사이트 공통 에디터(DHTML)로 씁니다.
- 치환자(본문·댓글)
    [이미지 주소]  [유튜브 주소]  [X(트위터) 글 주소]  → 임베드
    주소,라벨                                         → 라벨 링크 (라벨은 띄어쓰기 전까지)
    요1[접힌 내용]-접기 제목-                          → 접기
    제목1~7 / 소제1~7 / 기타1~7[텍스트]               → 텍스트 꾸미기(OTT 스킨의 텍스트 꾸미기 CSS 사용)

[디자인]
- 색은 관리자 > 디자인 설정 값을 따릅니다(기본 박스, 버튼, 포인트 색).
- 원본처럼 제목·본문·날짜 글꼴을 따로 쓰려면 style.css 맨 위의
  --bbscat-point-font / --bbscat-txt-font / --bbscat-sub-font 값을 바꾸세요.
