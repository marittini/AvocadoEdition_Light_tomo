다이어리 게시판 (custom_skin/diary) — 아보카도 에디션 라이트 TOMO

원본: diary_avocado (아보카도 에디션 퍼스널 일기 스킨)을 라이트 TOMO·PHP 8.4에 맞게 다시 작성했습니다.

[설치]
- 이 폴더를 skin/board/custom_skin/diary 에 둡니다.
- 관리자 > 게시판 관리에서 스킨을 custom_skin/diary 로 고릅니다.
- 한 페이지 글 수는 게시판 설정의 '페이지당 목록 수'를 따릅니다.

[화면]
- 목록: 연도(글이 있는 해만, ‹ › 로 이동) · 월(글이 있는 달만 누를 수 있음) · 날짜와 제목. 본문은 보이지 않습니다.
- 읽기: 날짜, 제목, 본문, 오른쪽 아래 서명(작성자 · 날짜).
- 쓰기: 사이트 공통 DHTML 에디터. 사진은 에디터에서 넣습니다.

[연도]
- 글의 작성 시각으로 연도·월을 나눕니다. 2026, 2027, 2028… 글이 생기면 자동으로 나타납니다.
- 답글로 해마다 묶는 방식은 쓰지 않습니다. 그누보드 답글은 한 글에 26개까지만 달 수 있어 1년치 일기를 담을 수 없습니다.

[디자인]
- 색은 관리자 > 디자인 설정을 따릅니다. 종이 = 기본 박스, 버튼 = 기본·포인트·기타 버튼, 선택한 달 = 포인트 색.
- 날짜·제목·본문·서명은 명조 계열(기기에 있는 나눔명조·본명조·AppleMyungjo·바탕 순)을 씁니다.
  다른 글꼴을 쓰려면 style.css 맨 위의 --diary-serif 값을 바꾸세요. 외부 웹폰트는 불러오지 않습니다.
