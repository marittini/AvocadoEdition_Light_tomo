갤러리 · 글 보관함 (custom_skin/gallery) — 아보카도 에디션 라이트 TOMO

원본: 사도세자 님 「[아보카도 에디션] 갤러리 스킨_mac」(gallery_thumb_mac 2.1, 대하 님의 썸네일형 갤러리 개조)

PHP 8.4 · 라이트 TOMO에 맞게 다시 작성하고, 그림과 글(소설)을 함께 보관할 수 있게 했습니다.

[설치]
- 이 폴더를 skin/board/custom_skin/gallery 에 둡니다.
- 관리자 > 게시판 관리에서 스킨을 custom_skin/gallery 로 고릅니다.
- 분류를 쓰려면 게시판 설정 [분류]에 분류를 적고(예: 그림|소설|커미션) [사용]에 체크합니다.
  분류를 쓰면 분류마다 접는 폴더로 보이고, 쓰지 않으면 쪽 나눔이 있는 목록으로 보입니다.
- 이미지를 올리려면 '파일 업로드 개수'를 1 이상으로 둡니다. 첫 번째 이미지가 목록 썸네일이 됩니다.
- 보호글을 쓰려면 최고관리자가 글쓰기 화면을 한 번 열어 주세요(보호글 비밀번호 칸을 만듭니다).

[화면]
- 목록: 분류 폴더를 누르면 펼쳐지고 접힙니다. 펼친 폴더는 브라우저에 기억됩니다.
  그림은 정사각 썸네일, 글은 같은 크기의 종이 카드(첫 줄 · 글자 수)로 보입니다.
- 카드를 누르면 목록 위에 본문이 뜹니다. 바깥을 누르거나 Esc, 닫기 버튼으로 닫습니다.
  주소도 그 글 주소로 바뀌어 그대로 공유할 수 있고, 뒤로 가기를 누르면 닫힙니다.
- 본문: 분류 · 제목 · 출처 · 날짜, 이미지, 내용, 같은 분류의 이전 글 / 다음 글(오래된 글 → 새 글), 댓글.
  글(소설)은 읽기 좋은 너비와 줄 간격으로 보이고 글자 수(공백 제외)를 함께 보여 줍니다.

[쓰기]
- 종류: 그림 / 글. 분류, 공개 범위, 제목, 출처(선택), 내용(사이트 공통 에디터), 이미지.
- 그림은 이미지만 올려도 됩니다(내용은 비워도 됨).
- 공개 범위: 전체공개 / 멤버공개(로그인한 회원) / 보호글(글마다 정한 비밀번호) / 비밀글(작성자 · 관리자).
  보호글 비밀번호는 암호화해서 저장합니다. 원본 스킨으로 쓴 보호글(평문 저장)도 그대로 열립니다.

[원본에서 바뀐 점]
- 본문 팝업이 그누보드 기본 본문 화면을 거칩니다(원본은 권한 확인을 건너뛰는 별도 view.php를 썼습니다).
- 보호글 비밀번호를 평문으로 저장하던 방식을 바꿨습니다.
- 글을 저장할 때마다 게시판 테이블을 고치던(ALTER) 코드를 없앴습니다.
- 맥 창 모양 장식(신호등 버튼 · 그라데이션)과 외부 아이콘 폰트(Font Awesome), 고정 글꼴을 없애고
  사이트 디자인 설정과 Material Icons를 따릅니다.
- 첨부 이미지와 썸네일은 비공개 파일 보호 경로(archive_file.php)로 보여 줍니다.

[디자인]
- 색과 글꼴은 지정하지 않습니다. 관리자 > 디자인 설정을 그대로 따릅니다.
  종이 = 기본 박스, 입력칸 = 입력폼, 버튼 = 기본 · 포인트 · 기타 버튼, 강조선 = 포인트 색.
