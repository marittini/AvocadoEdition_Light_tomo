방명록 (guestbook) — 아보카도 에디션 라이트 TOMO

원본: new_memo (늘 님) → 방명록 스킨 new_memo_l1 (사도세자 님, 아보카도 라이트)
https://www.postype.com/@sasasasado/post/14331108
PHP 8.4 · 라이트 TOMO에 맞게 다시 작성했습니다.

[설치]
- 이 폴더를 skin/board/guestbook 에 둡니다.
- 관리자 > 게시판 관리에서 스킨을 guestbook 으로 고릅니다.
- 한 쪽에 보이는 글 수는 '페이지당 목록 수'를 따릅니다.
- 게시판 너비는 '게시판 폭'을 따릅니다(비우면 720px).

[기능]
- 목록 화면 한 장에서 쓰기 · 읽기 · 수정 · 삭제 · 댓글을 모두 합니다.
- 댓글: '댓글 쓰기 권한'만 있으면 누구나 답니다(관리자가 아니어도 됨). 새 댓글은 아래에 붙습니다.
  글마다 '댓글 N'을 누르면 펼쳐집니다. 댓글을 달면 그 글로 돌아와 펼쳐진 채로 보입니다.
- 비밀글: 게시판 설정 '비밀글 사용'을 따릅니다. 관리자와 쓴 사람만 봅니다.
  비회원이 쓴 비밀글은 '비밀번호 입력'으로 열어 봅니다(그누보드 기본 비밀번호 확인을 씁니다).
- 비회원: 이름 · 비밀번호 · 자동등록방지를 입력합니다. 수정 · 삭제는 비밀번호 확인 뒤에 됩니다.
- #해시태그: 누르면 같은 태그가 들어간 글을 찾습니다(게시판 종류 설정 없이 됩니다).
- 주소(http…)는 자동으로 링크가 됩니다.
- 관리자에게도 IP는 보이지 않습니다.

[원본에서 바뀐 점]
- 비밀번호를 쿠키에 그대로 저장하던 방식을 없애고 그누보드 기본 비밀번호 확인을 씁니다.
- 글을 수정할 때마다 링크가 늘어나던 문제를 고쳤습니다. 원문은 그대로 두고 보여 줄 때만 링크로 바꿉니다.
- 목록을 그릴 때마다 게시판 테이블을 고치던(ALTER) 코드를 없앴습니다.
- 그누보드 기본 처리 파일(write.php, write_comment_update.php 등)을 복사해 두지 않고 기본 처리를 그대로 씁니다.
- 외부 아이콘 폰트(Font Awesome)를 쓰지 않고 사이트의 Material Icons를 씁니다.
- 텍스트 꾸미기는 쓰지 않습니다. 본문은 일반 텍스트이고, 주소 링크 · #해시태그 · 이모티콘 코드만 바꿔 보여 줍니다.
- 이모티콘: 글 · 댓글 칸의 '이모티콘' 버튼을 누르면 목록 창이 새 창으로 열리고(휴대폰은 화면 아래에서 목록이 올라옴), 고르면 커서 자리에 코드가 들어갑니다.
  이모티콘은 관리자 > 게시판관리 > 이모티콘관리에서 등록합니다(등록한 것이 없으면 버튼이 보이지 않음).
- 쓰기 요청마다 스킨 토큰을 확인합니다.

[디자인]
- 색과 글꼴은 지정하지 않습니다. 관리자 > 디자인 설정을 그대로 따릅니다.
  종이 = 기본 박스, 입력칸 = 입력폼, 버튼 = 기본 · 포인트 · 기타 버튼, 공지 · 해시태그 = 포인트 색.
