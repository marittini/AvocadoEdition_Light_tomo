링크 · 배너 게시판 (link) — 아보카도 에디션 라이트 TOMO

글 한 편 = 배너 한 개. 다른 사이트(갠홈) 배너를 모아 걸고, 홈 화면에도 보여 줄 수 있습니다.
예전 '링크 게시판(link.zip)' 스킨과 같은 칸(이름 wr_1 · 배너 그림 주소 wr_link1 · 주소 wr_link2 · 순서 wr_10)을 쓰므로
게시판 스킨만 link 로 바꾸면 기존 배너가 그대로 이어집니다.

[설치]
- 이 폴더를 skin/board/link 에 둡니다. 관리자 > 게시판 관리에서 새 게시판을 만들고 스킨을 link 로 고릅니다.
- 그림을 직접 올리려면 '파일 업로드 개수'를 1 이상으로 둡니다. DHTML 에디터는 쓰지 않습니다.
- 분류를 쓰려면 게시판 설정에서 '분류 사용'을 켜고 분류 목록을 적습니다(분류별로 묶어 보여 줍니다).

[배너 추가]
- 이름 · 주소(눌렀을 때 갈 곳) · 배너 그림(그림 주소 또는 그림 올리기) · 툴팁(마우스를 올리면 뜨는 말)과 툴팁 색.
- 쓰는 동안 위에서 배너와 툴팁을 미리 봅니다.
- '내 배너'(관리자만): 목록 맨 위에 두고, 다른 사이트에 붙일 배너 코드를 [배너 코드 복사]로 바로 복사합니다.
  그림을 올려 두면 코드 속 그림 주소가 바뀌지 않습니다(그림을 새로 올려도 같은 주소).

[배너 관리] (관리자)
- 목록 아래 [배너 관리]: 끌어서 또는 ↑ ↓ 로 순서를 바꾸고, 이름 · 주소 · 그림 주소 · 툴팁 · 분류 · 내 배너를 한 화면에서 고칩니다.
- 표시 방식: PC 한 줄 개수 / 휴대폰 한 줄 개수(또는 원래 크기대로), '홈 화면에도 보이기'.

[홈 화면에 배너 달기]
- [배너 관리]에서 '홈 화면에도 보이기'를 켜면 홈 화면 내용 아래에 배너가 나옵니다.
- 원하는 자리에 두려면 관리자 > 메인 화면 내용에 [배너] 라고 적습니다(게시판을 하나만: [배너:게시판아이디]).
- 홈 화면 배너에도 툴팁이 그대로 뜹니다. 비밀글 배너는 홈 화면에 나오지 않습니다.
