# 관리자 화면과 편집기 변경

환경설정·디자인·게시판 설정의 반복된 앵커 메뉴를 실제 탭으로 전환했습니다. 한 번에 한 패널만 보이며, 해시 주소와 방향키/Home/End를 지원합니다. 숨긴 패널의 값은 저장에서 제외하지 않습니다. 필수 입력 오류가 있는 패널은 자동으로 열립니다.

별도로 추가되었던 저장 전 미리보기 UI와 서버 처리 경로는 제거했습니다. 기존 디자인 가이드 미리보기는 유지합니다. DB관리 메뉴도 제거합니다.

디스크 화면은 닷홈 무료 플랜의 공개 사양인 500MB를 기준으로 사이트 폴더 파일의 사용 비율을 표시합니다. MB는 1,000,000바이트로 환산합니다. 이것은 호스팅 계정의 실시간 할당량 API가 아니라 파일 크기 측정값입니다. 다른 사이트, 메일, 계정 백업 등은 포함하지 않을 수 있습니다. DB의 DATA_LENGTH+INDEX_LENGTH 추정 합계는 따로 표시하며 그래프에 합산하지 않습니다. 변경된 요금제나 추가 용량은 자동 감지하지 않습니다.

작성 IP는 게시글과 댓글 옆에 표시하지 않습니다. 관리자에게 전달되는 닉네임 메뉴 안에서만 표시하며 일반회원 응답 HTML에는 해당 메뉴 항목을 생성하지 않습니다. 기록 자체와 차단 기능은 유지합니다.

## 캐릭터 첨부 오류

PHP 8.4에서 수정 전 캐릭터 두상·전신 파일 업로드를 실행하면 HTTP 500이 발생했습니다. 공통 저장 코드가 캐릭터 스킨에서 전송하지 않는 `bf_file[]`에 `count(null)`을 호출한 것이 원인입니다. 일반 첨부가 없는 경우 빈 배열로 처리하며 별도의 `wr_1_file`, `wr_2_file`은 보존합니다. 두상과 전신을 동시에 첨부하고 수정 화면에서 URL이 남는 것까지 검증했습니다. 일반 게시판 첨부도 별도로 검증합니다.

일반 첨부의 이미지 메타데이터 기본값을 숫자 0으로 변경했습니다. WebP 기능이 없는 서버에서는 정의되지 않은 GD 상수를 먼저 평가하지 않으며 원본 첨부로 처리합니다. 일반 첨부 교체 시에는 새 파일의 저장이 성공한 뒤 이전 파일을 정리합니다.

## Tiptap 편집기

신규 설치의 기본 편집기는 Tiptap입니다. 기존 설치는 **환경설정 → 편집기·이미지·콘텐츠 보호 → 본문 편집기 → Tiptap**을 선택해 저장합니다. 기존 편집기 선택은 강제로 변경하지 않습니다. 게시판에서는 DHTML 에디터 사용 및 HTML 작성 권한도 적용됩니다.

Tiptap 3.32.1의 MIT 패키지로 구성한 로컬 번들을 사용합니다. CDN, 클라우드 편집기 계정, 라이선스 키나 호스팅의 Node.js 설치가 필요하지 않습니다. 한국어 도구 모음, 문단 제목, 등록된 글꼴 선택, 크기·색상, 목록, 정렬, 링크, 표, 이미지, 실행 취소·다시 실행, 확장 화면을 지원합니다. 추가 도구에서 위·아래 첨자, 글자 배경색, 줄 간격과 문단 여백, 체크리스트, 코드 블록, 구분선, 접기·펼치기, 표 행·열 추가/삭제와 셀 병합/분할, 셀 배경색, 이미지 크기·설명·정렬, 찾기·바꾸기, HTML 편집, 유튜브 삽입과 특수기호를 제공합니다. 여러 이미지를 한 번에 선택할 수 있으며 이미지 모서리 드래그와 표 열 너비 조절도 지원합니다. 모바일에서도 같은 편집기를 사용합니다. 문단·글꼴·크기, 기본 서식 그룹, 추가 도구 메뉴를 분리하고 원본의 연분홍·회색과 사각 컨트롤을 사용합니다. 모바일 도구 버튼은 44px 터치 영역을 가지며 문서 표는 관리자 폼의 세로 배열 CSS와 분리합니다.

본문 이미지는 파일 선택·붙여넣기·드롭 시 서버로 업로드합니다. 세션 CSRF 토큰과 작성 권한을 확인하고 이미지 종류·크기·화소를 검증합니다. 기존 WebP 품질 설정을 사용하며 변환 불가 시 원본을 유지합니다. 업로드 중 저장을 막고 오류를 편집기 안에 표시합니다. 게시글 저장과 별도인 이미지 업로드이므로 작성 취소 시 업로드된 이미지가 남을 수 있습니다.

기존 HTML은 편집기의 지원 스키마로 읽고 저장합니다. 일반 문단·제목·서식·링크·목록·표·이미지를 지원하지만 임의 HTML 위젯이나 스크립트를 그대로 편집하는 도구는 아닙니다. 특수 HTML이 들어 있는 기존 메인 페이지는 백업 후 확인하거나 기존 편집기를 유지하세요.

### 유지보수

- PHP 통합: `plugin/editor/tiptap/editor.lib.php`
- 이미지 저장: `plugin/editor/tiptap/upload.php`
- 편집기 동작: `plugin/editor/tiptap/src/editor.js`
- 스타일: `plugin/editor/tiptap/editor.css`
- 배포 번들: `plugin/editor/tiptap/editor.bundle.js`
- 버전 고정: `package.json`, `package-lock.json`
- 제삼자 라이선스: `THIRD_PARTY_LICENSES.txt`

프런트엔드 수정 후 해당 편집기 폴더에서 `npm ci`와 `npm run build`를 실행해 번들을 갱신합니다. 이 빌드 작업은 개발 환경에서만 필요합니다.

## 검증

PHP 8.4.27 / MariaDB 11.8 및 실제 Chromium으로 검증했습니다. 닷홈 실계정에서 실행한 결과는 아닙니다.

- 관리자 탭 전환·키보드·해시 진입·숨긴 필수 입력 복구
- 기존 저장과 실패 시 입력 유지, 관리자 권한·CSRF
- 캐릭터 스킨 두상·전신 업로드, 일반 게시판 첨부·수정·삭제
- 디스크 분할 측정·DB 추정·500MB 그래프
- Tiptap 한글 본문·굵게 서식·이미지 업로드·저장 후 재편집
- 위조 토큰 및 SVG 업로드 거부
- HTML 적용 전 저장 방지, 표 행·열·셀 병합/분할, 이미지 다중 첨부와 크기/설명 변경, 접기·체크리스트·유튜브 저장/재편집
- 공개 화면 HTML 필터에서 안전한 편집기 블록 유지 및 스크립트·이벤트·미승인 iframe 차단
- 관리자 클릭 전/후 IP 표시와 일반회원 HTML에서 IP 항목 제외
- 320/390/768/1024/1440px 관리자 반응형 화면

`tests/admin_revision_smoke.cjs`의 일반회원 검증은 관리자와 같은 테스트 비밀번호를 설정한 `tomo_viewer`라는 일반회원 테스트 계정을 준비해 실행합니다. 모든 쓰기 테스트는 폐기 가능한 설치에서만 실행하세요.
