# 말머리 BBS 게시판 (bbscategory)

뀰님의 「[아보카도 에디션] 말머리 BBS 게시판」([배포글](https://www.postype.com/@kkyoul/post/19291007), `bbs_custum_category.zip`)을 아보카도 에디션 라이트 TOMO와 PHP 8.4에 맞게 이식했습니다. 원본은 사도세자님의 bbs_2를 바탕으로 지비님 데코 BBS·잉님 갠꾸팁을 참고했으며, 아보카도 퍼스널·PHP 5.5 기준입니다. 스킨 위치는 `skin/board/bbscategory/`입니다.

## 설치

1. 관리자 > 게시판 관리에서 스킨을 `bbscategory`로 고릅니다.
2. 게시판의 **분류 사용은 끕니다.** 말머리가 자동으로 카테고리가 됩니다. 켜 두면 글 저장 시 안내가 나옵니다.
3. 보호글을 쓰려면 최고관리자가 그 게시판의 글쓰기 화면을 한 번 엽니다. 보호글 비밀번호 칸(`wr_protect`)을 게시판 테이블에 추가합니다(OTT 스킨과 같은 방식).

원본은 코어 `bbs/write_update.php`의 분류 검사를 지우도록 안내했지만, 이식본은 게시판 분류를 쓰지 않고 스킨의 `write_update.head.skin.php`에서 말머리를 `ca_name`에 넣으므로 **코어 글쓰기 파일을 고치지 않습니다.** 원본처럼 목록을 열 때마다 게시판 설정(`bo_category_list`)을 덮어쓰지도 않습니다.

## 기능

- **말머리 카테고리:** 제목을 `말머리) 제목`으로 쓰면 목록 위 메뉴에 말머리와 글 수가 나타나고, 누르면 그 말머리 글만 봅니다. 제목에서는 말머리가 배지로 표시됩니다.
- **공개 범위:** 전체공개·비밀글·보호글(비밀번호)·멤버공개(로그인 회원). 목록에 자물쇠·열쇠·회원 아이콘으로 표시합니다. 보호글 비밀번호는 해시로 저장하고, 원본에서 평문으로 저장된 기존 보호글도 열 수 있습니다. 첨부·에디터 이미지도 같은 공개 범위로 보호합니다(`bbs/archive_file.php`에서 OTT 스킨과 같은 규칙 적용).
- **에디터:** 사이트 공통 DHTML 에디터로 작성·수정합니다(HTML 작성 권한이 있는 회원).
- **치환자(본문·댓글):** `[이미지 주소]`·`[유튜브 주소]`·`[X 글 주소]` 임베드, `주소,라벨` 라벨 링크, `요1[내용]-제목-` 접기, `제목1~7`·`소제1~7`·`기타1~7[텍스트]` 꾸미기. 새로 만드는 주소와 글자는 다시 이스케이프하며 http(s) 주소만 허용합니다. 텍스트 꾸미기 모양은 에디션에 포함된 OTT 스킨의 텍스트 꾸미기 CSS를 함께 불러옵니다.
- **관리:** 선택 삭제·복사·이동, 검색, 페이지, 이전글·다음글, 댓글(비밀댓글·답글·수정) 유지.

## 디자인

원본의 배치와 분위기(둥근 줄 목록, 가운데 말머리 메뉴, 말머리 배지, 가운데 제목·오른쪽 날짜, 본문 위 구분선, 왼쪽 이름 댓글, `M`·`X` 버튼)를 그대로 따릅니다. 색은 원본의 고정 색 대신 **관리자 > 디자인 설정** 값을 씁니다.

| 화면 요소 | 디자인 설정 |
|---|---|
| 목록 줄, 본문·글쓰기·댓글 상자 | 기본 박스 |
| 말머리 메뉴 | 선택: 포인트 버튼 / 나머지: 기타 버튼 (basic 스킨과 같은 규칙) |
| 제목의 말머리 배지 | 포인트 버튼 색 |
| 공개 범위 표시, 라벨 링크 | 기본 버튼 색 |
| 마우스 오버·댓글 수·접기 제목 | 포인트 색 |
| 선택삭제·복사·이동, 관리자, 본문 `X` | 기타 버튼 (basic 스킨 삭제 버튼과 같음) |
| 보호글 비밀번호 화면 | 사이트 비밀글 비밀번호 확인 화면(회원 스킨)과 같은 상자 |

원본의 적갈색 관리 버튼은 사이트 공통 CSS의 `.ui-btn.admin`(`#8c1e1e` 고정)이라 디자인 설정과 연동되지 않아 기타 버튼으로 바꿨습니다. 검색 버튼은 basic 스킨처럼 돋보기 아이콘입니다. 모바일 목록도 PC처럼 한 줄(제목 말줄임, 오른쪽 날짜)로 표시합니다.

원본이 외부에서 불러오던 웹폰트와 Font Awesome은 쓰지 않습니다. 글꼴은 디자인 설정의 기본 글꼴을 따르며, 원본처럼 제목·본문·날짜 글꼴을 나누려면 `style.css` 맨 위의 세 변수를 바꿉니다. 아이콘은 사이트에 이미 있는 Material Icons를 씁니다.

## 점검

PHP 8.3 + MariaDB 10.11 로컬 사이트에서 `tests/bbscategory_smoke.cjs`(말머리 메뉴·글 수·필터, 공통 에디터 작성, 접기·라벨 링크, 다른 회원의 멤버공개 열람, 보호글 틀린/맞는 비밀번호, 토큰 없는 글쓰기 차단)와 기존 `tests/pixiv_board_smoke.cjs`가 통과했습니다. 디자인 설정 색을 바꿔 스킨 색이 따라 바뀌는 것을 캡처로 확인했습니다. PHP 8.4 실서버, 외부 임베드(YouTube·X)의 실제 표시는 외부 접속을 막은 환경이라 확인하지 못했습니다.
