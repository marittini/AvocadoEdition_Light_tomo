# 다이어리 게시판 (custom_skin/diary)

`diary_avocado`(아보카도 에디션 퍼스널 일기 스킨)를 라이트 TOMO·PHP 8.4에 맞게 다시 작성했습니다. 스킨 위치는 `skin/board/custom_skin/diary/`입니다. 관리자 > 게시판 관리에서 스킨을 `custom_skin/diary`로 고릅니다.

## 원본에서 바꾼 것

| 원본 | 이식본 |
|---|---|
| 갤러리/목록 전환 | 목록만 |
| 목록에 본문 미리보기·첫 사진 | 날짜·요일·제목만 (본문 없음) |
| 에디터 없이 textarea, 사진은 별도 첨부 | 사이트 공통 DHTML 에디터, 사진은 에디터에서 |
| 본문을 정제 없이 `nl2br`로 출력 | 그누보드가 정제한 본문(`$view['content']`) 출력 |
| 첨부 이미지를 `data/file` 주소로 직접 연결 | 그누보드 첨부 출력(보호된 파일 경로) 사용 |
| 삭제 링크에 토큰 없음, 글쓰기 토큰 없음 | 코어의 수정·삭제 링크 사용, 글쓰기 토큰 검사 추가 |
| 연·월 필터 시 페이지 없이 전체 조회, `cal_days_in_month`(calendar 확장 필요) | 선택한 연·월만 페이지로 나눠 조회, 확장 없이 날짜 범위 계산 |
| 고정 초록색, 그림자, 반투명 유리 배경, 이모지 아이콘 | 디자인 설정 색, 테두리 상자, Material Icons |
| `skin/board/diary_avocado` 고정 경로 | 스킨 폴더 기준 경로 |

## 연도 지원

글의 작성 시각(`wr_datetime`)으로 연도와 월을 나눕니다. 글이 있는 연도는 2026, 2027, 2028… 모두 자동으로 나타나고, 목록 위 `‹ ›`로 이전·다음 해로 이동합니다. 기본으로는 가장 최근 연도를 보여 줍니다.

답글로 연도 글 아래에 일기를 다는 방식은 쓰지 않습니다. 그누보드 답글은 한 글에 26개까지만 달 수 있어(`bbs/write.php`) 1년치 일기를 담을 수 없고, 목록·검색·페이지가 모두 답글 구조에 묶이게 됩니다.

## 디자인

첨부 이미지처럼 편지지에 쓴 글의 분위기를 목표로 했습니다. 넓은 여백, 명조 계열 본문, 가는 구분선, 오른쪽 아래 서명(작성자와 날짜)입니다.

| 화면 요소 | 디자인 설정 |
|---|---|
| 종이(목록·읽기·쓰기 상자) | 기본 박스 |
| 글쓰기·작성 | 포인트 버튼 |
| 수정·목록·이전글·다음글·취소 | 기본 버튼 |
| 삭제·관리자 | 기타 버튼 |
| 선택한 달, 마우스 오버 | 포인트 색 |

날짜·제목·본문·서명은 명조 계열을 쓰고(기기에 있는 나눔명조·본명조·AppleMyungjo·바탕 순), 버튼 등은 디자인 설정의 기본 글꼴을 따릅니다. 다른 글꼴은 `style.css`의 `--diary-serif`로 바꿉니다. 외부 웹폰트는 불러오지 않습니다.

## 점검

PHP 8.3 + MariaDB 10.11 로컬 사이트에서 `tests/diary_smoke.cjs`가 통과했습니다. 공통 에디터 작성, 목록에 본문 미노출, 2025~2028년 이동, 글이 있는 달만 선택, 월 필터, 페이지, 비밀글 표시, 읽기 서명, 목록 복귀 시 연·월 유지, 토큰 없는 글쓰기 차단을 확인합니다. 댓글은 원본처럼 표시하지 않습니다. PHP 8.4 실서버에서는 실행하지 않았습니다.
