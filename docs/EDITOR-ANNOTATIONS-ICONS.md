# 개인 백업 블로그 편집기 보완

기준: 원격 기본 브랜치 `master`, `be240b8` (PR #6 병합 상태).
이 버전에는 이미 Tiptap 3.32.1이 포함되어 있으므로 새 편집기를 중복 설치하지 않고 기존 Tiptap을 확장합니다. SmartEditor·CHEditor 선택지, 기존 게시판·표·체크리스트·접기·유튜브·폰트 등록·품질 설정은 유지합니다. 기존 설치의 에디터 선택값을 자동으로 바꾸지 않습니다.

## 참고와 구현 범위

[BearEditor 공개 데모](https://babyfirebear.naru.pub/)의 HTML·JS·CSS를 읽어 기능과 연결 구조를 조사했습니다. [제작자 안내](https://babyfirebear.tistory.com/37)의 무료 기본설치 문구는 확인했지만 일반적인 수정·재배포 라이선스는 확인되지 않았습니다. 제작자의 개발 방식·판매·유지보수에 관한 평가는 검증하지 않았습니다.

이번 변경은 데모의 코드·그림·로고·폰트를 복사하거나 데모 서버를 호출하지 않습니다. 루비·스포일러·자간·이미지 관리의 사용 목적을 참고해 현재 프로젝트의 MIT Tiptap 엔진과 PHP 업로드 경로에 맞게 별도로 작성했습니다. 호스팅에 Node.js·외부 편집기 계정·라이선스 키는 필요하지 않습니다.

| 항목 | 기준 버전 | 변경 후 |
| --- | --- | --- |
| 기본 도구 | 이미 아이콘 사용 | 보존 |
| 추가 도구 탭 | 긴 글자 버튼 | SVG 아이콘, 한국어 접근성 이름·title·포커스 안내 |
| 추가·표·이미지·HTML 작업 | 긴 글자 버튼·넓은 격자 | 기능별 SVG 아이콘, 필요한 입력란만 설명 유지 |
| 루비 | 없음 | 선택 글자에 발음·설명 추가, 수정·해제, HTML 저장·재편집 |
| 스포일러 | 없음 | 블러 표시, 열람 시 클릭·Enter·Space로 전환 |

| 이미지 관리 | 바로 본문에 첨부 | 기존 방식 보존 + 별도 관리창에서 다중 업로드 후 선택 삽입 |

| 모바일 | 기존 반응형 | 아이콘 44px 터치 영역, 320px 이상 가로 넘침 검사 |

## 데이터와 보안

- 루비는 `ruby`·`rt`·`rp`로 저장합니다. 발음 문자열은 HTML로 삽입하지 않으며, 서버 HTML Purifier에 세 요소만 추가 허용합니다. 정의 캐시 버전을 올려 이전 필터 캐시와 구분합니다.
- 블러는 `tomo-spoiler` 클래스와 공통 외부 JS로 동작합니다. 게시글에 실행 스크립트를 끼워 넣지 않습니다. 블러는 비공개 권한·암호화가 아닙니다. 허용된 독자는 원문을 볼 수 있습니다.
- 자간은 Tiptap textStyle 속성으로 저장하고 기존 서식 속성과 함께 유지합니다.
- 관리창은 현재 문서와 현재 편집 화면에서 업로드한 이미지만 표시합니다. 서버 전체 파일 목록을 공개하지 않습니다. 새로 연 다른 글의 업로드 이력을 보여주는 서버 자산 관리자는 아닙니다.
- 기존 PHP 업로드의 세션·CSRF·작성 권한·MIME/화소/용량 검사와 WebP 품질 설정을 사용합니다. 변환 성공 시 업로드 원본을 삭제하고, 변환 실패·움직이는 GIF·기존 WebP의 정책도 유지합니다.
- 본문 제거·목록 제외는 서버 파일 삭제가 아닙니다. 다른 글의 참조를 깨뜨리지 않습니다. 작성 취소·목록 제외 후 서버 파일이 남을 수 있으며 자동 삭제 기능은 이번 범위에 없습니다.
- 이미지 삽입·제거는 실행 기록으로 되돌릴 수 있습니다. 여러 이미지는 순차 업로드하고 배치 전체가 끝나기 전 저장을 막습니다.
- 기존 임의 HTML 위젯·스크립트 보존 제한은 기존 Tiptap의 제한과 같습니다. 새 HTML 범용 에디터를 만든 것은 아닙니다.

## 검증

PHP 8.4.27, MariaDB 11.8.6의 폐기 가능한 설치와 Chromium으로 확인했습니다. 닷홈 실계정 배포 결과는 아닙니다.

- `tests/editor_annotations_smoke.cjs`: 실제 도구를 통한 루비·블러·자간, HTML 왕복과 저장·재편집, 업로드 관리창에서 삽입 전 대기, WebP 결과, 파일명의 HTML 무실행, 본문 제거·실행 취소, 위조 토큰·비로그인 업로드 거부, 비공개 파일 PHP 게이트, 공개 화면 키보드 블러 전환, 320/390/768/1440px 넘침·포커스 안내·모바일 터치 크기.
- `tests/tiptap_features_smoke.cjs`: 기존 표/행/열/병합/분할, 다중 이미지·크기·설명·정렬, 체크리스트·접기·유튜브·찾기·바꾸기, HTML 미적용 저장 방지와 재편집.
- `tests/editor_empty_smoke.cjs`, `tests/editor_empty_test.php`: 빈 본문·공지와 미디어 본문 구분 회귀 검사.
- `tests/editor_html_test.php`: 안전한 루비·블러·자간·기존 블록 유지, 스크립트·이벤트·미승인 iframe 차단.
- `tests/archive_test.php`: 기존 이미지 변환·원본 삭제/실패 보존 검사.
- 전체 PHP 문법, JS 문법, 배포 번들 빌드와 Git 공백 검사.

Apache `.htaccess`에 의한 직접 이미지 URL 차단, 실제 모바일 기기·스크린리더, 모든 외부 스킨은 이번 로컬 검증에 포함되지 않습니다. 기존 HTML Purifier의 PHP 8.4 deprecated 알림은 남아 있습니다. PHP 테스트에서는 deprecated 알림을 제외하고 실행했고, 애플리케이션 설정은 기존 로그 정책을 사용했습니다.

## 실제 화면

PHP 테스트 설치를 열어 동일한 예시 본문과 추가 서식 패널을 Chromium으로 캡처했습니다. 이전 화면은 기준 커밋의 JS·CSS를 브라우저에서 불러온 비교이며 서버 데이터는 변경하지 않았습니다.
