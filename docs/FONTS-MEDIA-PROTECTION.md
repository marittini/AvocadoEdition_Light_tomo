# 웹폰트·WebP 품질·콘텐츠 보호

## 웹폰트를 목록에서 바꾸기

1. **관리자 → 디자인 설정 → 웹폰트 등록**에서 ‘웹폰트 추가’를 누릅니다.
2. 구별하기 쉬운 표시 이름과 CSS에서 쓰는 정확한 `font-family`를 입력합니다. 예: 표시 이름 `프리텐다드`, family `Pretendard`.
3. 눈누나 Google Fonts에서 제공하는 `@font-face` 또는 `@import` CSS를 붙여넣습니다. 이미 기존 폰트 CSS에 등록한 글꼴이면 해당 CSS를 다시 붙이지 않고 이름/family만 등록해도 됩니다.
4. 기본 글자·메뉴 툴팁·대문 안내문의 ‘등록한 웹폰트 선택’에서 글꼴을 고르고 저장합니다. 등록만 해서는 사이트 글꼴이 바뀌지 않습니다.
5. 실제 공개 페이지를 새로고침해 확인합니다. 폰트 서버의 주소·CORS·라이선스·가중치는 등록한 CSS를 따릅니다. 관리자에서는 웹폰트 등록 탭에서 추가하고 화면 디자인 탭에서 선택합니다. 가이드 미리보기로 저장된 디자인을 확인할 수 있습니다.

기존 ‘폰트 스타일’ CSS와 직접 입력값은 유지합니다. `직접 입력`을 선택하면 원하는 CSS font-family 문자열/스택을 입력할 수 있습니다. 목록에 없는 기존 값도 표시합니다. 사용 중인 등록 폰트를 삭제하거나 family를 변경하려면 먼저 세 적용 영역에서 다른 글꼴을 선택하세요. 폰트별 `id`는 서버가 생성하며 표시 이름 수정으로 바뀌지 않습니다.

등록은 최대 50개, 전체 데이터 60KB입니다. 기존 폰트 CSS는 자동으로 목록화하거나 외부에서 다운로드하지 않습니다. 동일한 family는 중복 등록하지 않습니다. `@import`는 CSS 생성 시 다른 규칙 앞으로 배치합니다. 등록 CSS는 소유자가 입력하는 코드이므로 HTML 태그가 아닌 유효한 CSS만 넣으세요.

## WebP 품질

**관리자 → 환경설정 → 이미지 및 콘텐츠 보호**에서 0~100 정수를 설정합니다. 기본은 **95**입니다. 기존 설치도 이 기능 적용 후 새 변환부터 기본 95를 사용합니다. 0은 최저 품질이며 100도 무손실 모드는 아닙니다.

적용 경로는 새 게시판 첨부, SmartEditor/CHEditor 업로드의 공통 변환기, 새 WebP 썸네일입니다. 기존 WebP·애니메이션 GIF는 재변환하지 않고 기존 파일은 일괄 변환/삭제하지 않습니다. 이미 있는 썸네일의 캐시는 기존 정책대로 사용합니다. 새로 생성하거나 기존 시스템에서 재생성이 필요해진 썸네일부터 새 품질을 사용합니다.

원본을 축소하지 않습니다. 변환 파일의 생성·디코딩·크기를 확인한 뒤 업로드 원본을 정리하는 기존 정책을 유지합니다. 변환 실패 시 원본을 유지합니다. 품질 수치는 최종 파일 용량의 상한을 보장하지 않습니다.

## 콘텐츠 보호

환경설정에서 아래 항목을 각각 켭니다. 설치/업데이트 기본값은 모두 OFF입니다.

- 우클릭 제한
- 이미지 드래그 제한
- 본문 선택·복사 제한

공개 HTML 문서와 공통 헤더를 사용하는 사이트 iframe 내부에 적용됩니다. 입력창, textarea, select, 버튼, 편집 가능 영역과 관리자 화면은 제외합니다. 사용자 스킨에서 의도적으로 복사를 허용할 구간은 `data-tomo-allow-copy` 속성을 지정합니다. 공통 헤더를 사용하지 않는 외부 문서나 외부 사이트 iframe은 대상이 아닙니다.

이 기능은 브라우저 동작 제한입니다. 스크린샷·개발자 도구·별도 HTTP 요청 등 모든 복제를 차단하거나 게시글/파일 권한 검사를 대체하지 않습니다.

## 설치·업데이트·복구

새 설치는 설정 테이블에 전용 필드가 만들어집니다. 기존 설치는 최고관리자로 환경설정 또는 디자인 설정을 열 때 누락된 필드만 추가합니다. DB 계정의 ALTER 권한이 필요합니다. 실패하면 안내를 표시하며 웹 요청마다 재시도하지 않습니다. 다시 관리자 설정을 열어 재시도할 수 있습니다.

| 필드 | 내용 | 기본값 |
|---|---|---|
| `cf_tomo_fonts` | ID·표시 이름·family·CSS 목록 JSON | NULL / 빈 목록 |
| `cf_tomo_webp_quality` | WebP 인코딩 품질 | 95 |
| `cf_tomo_protection` | 우클릭=1, 이미지 드래그=2, 선택/복사=4의 합 | 0 |

`cf_1`~`cf_10` 같은 기존 여분 필드를 사용하지 않습니다. 폰트 적용값은 기존 CSS 설정 행의 family 문자열로 유지합니다. 마이그레이션을 반복해도 설정을 초기화하지 않습니다.

배포 전 파일+DB를 백업하세요. 이전 프로그램으로 돌아갈 때 추가 필드를 즉시 삭제할 필요는 없습니다. 폰트는 기존 직접 입력/폰트 CSS로 옮길 수 있습니다. 이전 버전의 무손실 WebP 정책으로 되돌려도 이미 품질 95로 저장된 파일이 원래 품질로 복구되지는 않으며, 원본이 필요하면 배포 전 백업을 사용해야 합니다.
