# 개인 백업 블로그 개선 구현 기록

기준: AvocadoEdition_Light c670d0e. 관리자 = 소유자. 글쓰기 대시보드나 새 콘텐츠 플랫폼을 추가하지 않습니다. 기존 게시판·회원·스킨·메뉴·꾸미기·커스텀 코드 경로를 보존합니다.

## 구현 범위

- 짧은 PHP 여는 태그를 정식 태그로 변환하여 서버 설정 의존성을 줄였습니다.
- PHP 8에서 제거된 magic quotes/each/create_function/__autoload, 중괄호 오프셋, 역순 implode 등을 수정했습니다. mysqli 실패 결과와 설치 CSS 초기화 문제를 수정했습니다.
- 관리자에 덧붙이는 반응형 스타일, 메뉴 토글, 도움말, 항목 찾기, 미저장 경고와 취소를 추가했습니다. 기존 필드를 제거하지 않았습니다.
- 환경·디자인·메인·메뉴 설정은 비동기 저장으로 실패 시 입력을 유지합니다. 서버의 기존 토큰 검사는 유지하고 누락된 디자인/메인 저장 권한·토큰 검사를 보완했습니다.
- 디자인/메인/메뉴에 저장과 분리된 미리보기를 추가했습니다. 디자인은 기존 CSS 생성기와 가이드 구성요소를 사용하고, 메뉴는 이름·순서의 구조 예시입니다. 실제 스킨·하위 메뉴의 모든 표현과 동일하다고 보장하지 않습니다.
- 미리보기는 비공개 POST 요청, 소유자 검사, 전용 CSRF 토큰, no-store, sandbox iframe(스크립트와 동일 출처 권한 없음), CSP를 사용합니다. 외부 요청·폼·스크립트는 실행하지 않습니다. 임시 이미지 파일은 저장하지 않고 요청 메모리에서만 제한적으로 표시합니다. 이미지당 2MiB 제한입니다. 실제 게시글 대신 디자인 가이드 예시를 사용합니다.
- 디스크 측정은 프로그램 폴더 내 파일의 **논리 크기**입니다. 폴더 분할 측정/일시 정지/재개/재측정, 분류·시각·누락·링크 건너뜀 상태를 제공합니다. 심볼릭 링크를 따라가지 않습니다. 측정 상태는 관리자 세션에 보관됩니다. FTP 변경은 재측정으로 확인합니다.
- **닷홈 계정 전체 사용량/잔여량과 DB 포함 기준은 미확인**입니다. 서버 전체 여유 공간을 계정 여유 공간으로 표시하지 않고, 가짜 500MB 막대를 표시하지 않습니다. DB 합계 자동 조회는 구현하지 않았습니다.
- 첨부와 SmartEditor/CHEditor 이미지 경로에 공통 WebP 변환을 추가했습니다. 공통 변환기는 JPEG·PNG·정지 GIF·BMP를 지원하며 각 업로드 경로의 허용 형식은 별도로 적용됩니다. 기존 WebP와 애니메이션 GIF는 재압축하지 않습니다. 자동 변환이 불가능하면 원본을 보관하며 첨부 경로는 경고를 표시하고 에디터는 응답 경고/서버 로그에 기록합니다.
- **2026-10-30 정책 변경: 변환된 WebP만 보관합니다.** 지원하는 새 정지 이미지 업로드는 WebP 생성·전체 디코딩·크기 검증 후 원본을 삭제합니다. 원본 삭제 실패 시 변환본을 회수하고 원본으로 첨부합니다. 기존 WebP/애니메이션 GIF와 미지원 형식·변환 실패 파일은 삭제하지 않습니다. 품질 설정(현재 기본 95)·최대 24메가픽셀·메모리 검사 정책은 유지하며 60KB를 보장하지 않습니다. 과거 보존형 업로드의 메타데이터/삭제 호환성은 유지하고 기존 자료·FTP 파일을 일괄 변환/삭제하지 않습니다.
- WebP의 표시·mmb 이미지 선택·썸네일 처리를 보완했습니다. GIF/애니메이션 WebP의 프레임 보존 변환은 새로 구현하지 않았습니다.
- 첨부·편집기 파일 권한 확인용 `bbs/archive_file.php`와 설치용 Apache 규칙을 추가했습니다. 원본·변환본·게시판 썸네일은 게시글 권한을 확인합니다. 편집기 파일은 읽을 수 있는 글/내용 페이지 참조를 확인하며 미참조 파일은 소유자만 접근합니다. 실제 Apache rewrite 검증 전에는 보호 완료로 판단하지 않습니다.

## 검증 결과와 한계

로컬 PHP 8.4.27 + MariaDB 11.8의 격리된 테스트 사이트에서 수행:

- PHP 파일 전체 구문 검사, JavaScript 구문 검사.
- 공통 라이브러리: PNG→WebP, 무손실 픽셀·투명도, 변환 성공 후 원본 삭제·실패 시 원본 유지, 문서 비변환, 기존 WebP 미재압축, 분할 측정·합계·심볼릭 링크 제외·동반 원본 삭제.
- Chromium: 관리자 5개 화면 HTTP 200, 기존 디자인 필드 100개 이상 유지, 미리보기/CSP/sandbox, 디스크 실측 완료, 설정 저장 후 재조회, 실패 시 입력 보존, 위조 토큰·비인증 요청, 모바일 390px 가로 넘침 없음, JavaScript 오류 없음.
- SmartEditor: 인증 nonce를 사용한 본문 이미지 업로드가 WebP URL·크기·타입으로 반환됨.
- Chromium: 그룹/게시판 생성, PNG 첨부가 WebP로 등록·표시, 소유자 파일 접근/비회원 거부, 글 수정·삭제.
- 파일: 테스트 사이트 data 폴더를 TAR로 내보내 별도 폴더에 복원하고 전체 파일을 비교.
- DB: SQL 내보내기 후 별도 DB로 32개 테이블 복원 및 행 수 비교. 테스트 DB는 복원 확인 후 삭제.

아직 검증하지 않은 것:

- 닷홈 PHP/GD/EXIF/업로드/메모리/Apache rewrite/HTTPS 실제 조건과 운영 성능.
- Apache의 직접 URL 규칙 자체(로컬 PHP 개발 서버는 .htaccess를 적용하지 않음). PHP 권한 게이트는 테스트했습니다.
- 모든 스킨·외부 SNS·메일/구형 플러그인의 전체 회귀. 레거시 선택 필드 관련 경고가 서버 로그에 남을 수 있습니다. 운영 화면에는 PHP 오류를 노출하지 않습니다.
- 실기 모바일/스크린리더, 새 선택 이미지의 모든 형식, 모든 편집기의 전체 UI 경로.
- GUI 백업·복원/예약 백업은 추가하지 않았습니다. 파일+DB 수동 백업/복원 절차는 아래 문서를 따릅니다.

## 로컬 검사

PHP 8.4와 mysqli, GD(WebP), mbstring, iconv, EXIF 등을 지원하는 환경을 사용합니다. 테스트 자격증명이나 데이터 폴더를 Git에 넣지 마세요.

```
php tests/archive_test.php
find AvocadoEdition_Light -name '*.php' -print0 | xargs -0 -n1 php -l
node --check AvocadoEdition_Light/adm/js/archive-admin.js
```

Playwright/Chromium이 설치된 환경의 **일회용 테스트 사이트**에서만:

```
TEST_URL=http://127.0.0.1:8094 TEST_USER=owner TEST_PASSWORD=... node tests/http_smoke.cjs
TEST_URL=http://127.0.0.1:8094 TEST_USER=owner TEST_PASSWORD=... TEST_IMAGE=/path/to/test.png node tests/board_smoke.cjs
TEST_DB=avocado_test TEST_SOCKET=/path/to/mysql.sock php tests/recovery_test.php
```

HTTP 테스트는 테스트용 설정/게시판/글을 변경하므로 운영 사이트에서 실행하지 않습니다.

## 모바일 후속 개선

- 관리자 폼·표·메뉴·미리보기·측정 화면의 좁은 폭 대응과 터치 영역을 보완했습니다. 관리자 강조색은 기존 분홍 계열에서 대비를 확보한 색을 사용하고 회색/분홍 톤을 유지합니다.
- 공개 블로그에는 작은 화면에서만 적용되는 레이아웃 보완을 추가했습니다. 저장된 색·배경·폰트를 바꾸지 않습니다. 본문 이미지·작성 폼·목록 스크롤·모바일 메뉴와 화면 확대를 지원합니다.
- 320/390/768/1024/1440px Chromium 뷰포트에서 관리자와 블로그의 실제 화면 렌더링·가로 넘침·메뉴 조작을 검사합니다. 실기 기종별 검증이나 모든 사용자 커스텀 코드의 반응성을 보장하지는 않습니다.

## 웹폰트·이미지 품질·콘텐츠 보호 후속 구현

등록한 웹폰트의 선택 목록, 관리자 WebP 품질(기본95), 공개 화면 보호 항목별 설정을 추가했습니다. 과거 검증 기록의 무손실 픽셀 검사는 이전 기본 정책에 관한 기록입니다. 현재 변환 기본값은95이며 설정값이 실제 인코더에 전달되는지 별도 테스트합니다. [사용법](FONTS-MEDIA-PROTECTION.md), [구조 점검](ARCHITECTURE.md), [개발 안내](DEVELOPMENT-GUIDE.md)를 참고하세요.
