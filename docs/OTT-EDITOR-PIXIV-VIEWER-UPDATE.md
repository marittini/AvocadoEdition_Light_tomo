# OTT 공통 에디터 및 픽시브 보완

OTT는 에디션 공통 에디터를 사용하며 HTML 작성 권한을 따릅니다. 기존 일반 텍스트 게시물은 기존 출력 경로를 유지하고, 공통 에디터로 작성한 HTML은 공통 정제 경로로 출력합니다. 게시물 작성자와 날짜는 화면에서 출력하지 않고 DB 값은 보존합니다.

픽시브 목록·상세에 업로드 날짜를 표시합니다. 카테고리와 태그는 기본 ui-btn(btn_default), 선택 ui-btn point(btn_point)를 사용합니다. 표지 버튼의 빈 영역에도 콘텐츠 보호 설정에 따른 우클릭 제한이 적용됩니다. 이 기능은 파일 접근 권한을 대체하지 않습니다.

확대창 크기는 이미지 비율과 화면 크기로 계산하며 닫기·이동 버튼용 여백을 확보합니다. 테마 전역 transition이 이미지 비율을 깨뜨리지 않도록 제한합니다.

작업 서버 연결이 끊기기 전 PHP 8.4 및 브라우저에서 공통 에디터 저장·수정, 연속 Enter, 작성자·날짜 비노출, 픽시브 날짜·우클릭 이벤트·가로/세로 팝업 치수·모바일 닫기·버튼 색상 비교를 확인했습니다. 연결 중단 후 동일 변경을 GitHub 기준 파일에 재적용했으며 해당 원격 커밋에 대한 추가 실행 검증은 환경 복구 후 필요합니다.

## 관리 버튼 색

목록의 선택삭제·관리자 버튼과 상세의 삭제 버튼이 사이트 공통 CSS의 `.ui-btn.admin`(`#8c1e1e` 고정 적갈색)을 써서 디자인 설정과 연동되지 않았습니다. basic 스킨의 삭제 버튼과 같은 기타 버튼(`ui-btn etc`)으로 바꿔 관리자 > 디자인 설정의 기타 버튼 색을 따릅니다.
