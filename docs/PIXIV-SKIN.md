# Pixiv 형식 게시판 스킨

## 설치

기존 서버 파일과 DB를 백업한 뒤 변경 파일 전용 ZIP의 `UPLOAD` 안의 내용만 서버의 기존 `common.php`가 있는 폴더에 올립니다. 설치 화면은 다시 실행하지 않습니다. 스킨 파일은 `skin/board/pixiv/`에 있고, `adm/admin.lib.php`의 변경은 중첩된 스킨을 관리자 선택 목록에 표시하기 위한 것입니다. 서버에서 이 파일을 직접 수정했다면 덮어쓰기 전에 비교하세요.

관리자에서 **새 일반 게시판**을 만든 후 디자인/양식의 스킨 디렉토리를 `pixiv`로 지정합니다. 게시판의 기본 분류 기능은 끄고 스킨의 일러스트·만화·소설 분류를 사용합니다. 첨부 가능 개수와 파일 크기, 글쓰기·읽기·댓글 권한은 게시판 설정에서 정합니다. 소설을 꾸며 작성하려면 게시판의 DHTML 에디터 사용을 켜고 사이트에서 Tiptap을 선택합니다. 시리즈 기능을 처음 사용할 때 스킨이 `{접두사}pixiv_series`, `{접두사}pixiv_series_work` 두 테이블을 자동으로 만듭니다(캐릭터 스킨의 전신 이미지 테이블과 같은 방식). DB 계정에 `CREATE` 권한이 없으면 시리즈 탭과 선택란이 나타나지 않고 나머지 기능은 그대로 동작합니다. `LOCK TABLES` 권한은 필요하지 않습니다.

**기존에 사용 중인 게시판에 바로 적용하기보다 새 게시판에서 사용하세요.** 이 스킨은 해당 게시판 글의 여분 필드 `wr_1`~`wr_10`에 분류·태그·순서·설명을 저장합니다. 다른 스킨에서 작성한 게시글은 이 스킨에서 수정하지 못하도록 막지만, 기존 스킨과 데이터 형식이 호환된다는 뜻은 아닙니다. 스킨 변경 전에는 반드시 백업하고, 기존 글은 원래 스킨에서 수정하세요.

## 사용

- 첫 화면은 썸네일 목록입니다. 가운데 분류와 장르 태그로 좁혀 볼 수 있고, 태그를 여러 개 선택하면 모두 포함하는 글만 표시합니다.
- 작품 상세에서는 표지만 표시합니다. 표지를 누르면 이미지 본문을 세로로 볼 수 있고, 본문 이미지를 누르면 그 페이지부터 가로 만화 뷰어가 열립니다. 뷰어의 좌우 버튼·방향키·모바일 스와이프·페이지 목록·슬라이더를 사용할 수 있습니다.
- 소설은 본문을 스크롤하거나 책처럼 페이지를 넘길 수 있습니다. `Aa`에서 글자 크기와 줄 간격을 조정합니다. EPUB 파일 업로드 기능은 아닙니다.
- 글쓰기에서 여러 이미지 파일을 한 번에 선택하고, 썸네일을 끌거나 앞/뒤 버튼으로 순서를 조정합니다. 수정 시 기존 이미지를 삭제하거나 새 이미지를 추가할 수 있습니다. 각 이미지의 ‘대표로 지정’을 선택하면 본문 순서와 관계없이 해당 이미지가 표지가 됩니다. 선택하지 않은 기존 글은 첫 번째 이미지를 표지로 사용합니다. 대표 이미지를 삭제하면 남은 첫 번째 이미지가 대신 지정됩니다.
- 태그는 쉼표로 구분해 직접 입력하거나 공개 글에서 이미 사용된 태그를 선택합니다. 태그는 최대 20개, 합계 240바이트이며 글자·숫자·밑줄·하이픈을 지원합니다. 비밀글 태그는 추천 목록에 노출하지 않습니다.
- 제목과 별도의 설명은 상세의 태그 아래에 제목 없이 표시합니다. 댓글은 기존 아보카도의 권한·비밀댓글·답변 처리를 사용하고 작성자의 닉네임을 표시합니다.

첨부 순서 정보는 기존 게시판 필드에 저장하므로 순서 문자열은 최대 250바이트이고 파일 슬롯은 최대 100개입니다. 실제 첨부 개수는 이보다 작은 게시판·PHP·호스팅 설정이 우선합니다. 설명은 최대 1,600바이트, 소설 본문은 기존 엔진 제한인 최대 65,536바이트이며 초과하면 저장 전에 안내합니다. 다량의 이미지에 대해서는 호스팅의 전체 전송 크기와 디스크 용량도 영향을 줍니다. 첨부·정렬과 읽기 뷰어는 자바스크립트와 현대적인 브라우저가 필요합니다.

## 시리즈

- 글쓰기의 **시리즈** 칸에서 기존 시리즈를 고르거나 ‘+ 새 시리즈 만들기’로 바로 만듭니다. 새로 넣은 작품은 마지막 화가 됩니다. 시리즈는 회원 작품에만 쓸 수 있고, 작성자 본인의 시리즈만 고를 수 있습니다(관리자는 게시판의 모든 시리즈).
- pixiv처럼 **만화 시리즈**(일러스트·만화)와 **소설 시리즈**를 구분합니다. 종류가 다른 작품은 넣을 수 없습니다.
- 목록의 **시리즈** 탭에서 시리즈를 모아 보고, 시리즈 페이지에서 처음부터 읽기·최신화·1화부터/최신화부터 정렬을 사용합니다. 작품 카드에는 제목과 시리즈 이름이 표시됩니다.
- 작품 상세에는 ‘시리즈 이름 #화수’와 이전 화/다음 화가 표시됩니다. 뷰어 마지막 장 다음(소설은 끝)에서 다음 화로 바로 넘어갈 수 있습니다.
- 시리즈 페이지의 **시리즈 편집**(작성자·관리자)에서 제목·설명·화 순서를 바꾸거나 작품을 시리즈에서 뺍니다. 시리즈를 삭제해도 작품은 남습니다. 게시물을 삭제하면 시리즈에서도 자동으로 빠집니다.
- 비밀글은 화수 번호는 유지하되 작성자·관리자 외에는 시리즈 목록·이전/다음 화에 노출하지 않습니다.

## 뷰어

- 표지(또는 ‘모두 보기’)를 누르면 모든 장을 세로로 보고, 이미지를 누르면 그 장부터 한 장씩 보기가 열립니다. 한 장씩 보기에는 쪽수, 슬라이더, 썸네일 ‘목록’, 이미지 좌/우 절반 클릭, 방향키·스와이프, ‘세로 보기’ 전환이 있습니다.
- 소설은 `Aa`에서 스크롤/페이지 넘김을 고르고 글자 크기·줄 간격을 바꿉니다. 페이지 넘김에서는 방향키도 사용할 수 있습니다.

## 점검

PHP 8.4와 MariaDB, Chromium 테스트 서버에서 새 게시판 선택, 다중 업로드, 저장 전·수정 후 순서, 기존 이미지 삭제와 추가, 설명, 태그 교집합, 비밀글 이미지와 태그 접근 차단, 위조 요청 및 타인 글 수정 차단, 모바일 작성, 이미지 스크롤/만화 보기, 긴 소설 페이지 넘김, Tiptap 연동을 확인했습니다. 시리즈는 PHP 8.3 + MariaDB 10.11 격리 사이트에서 `tests/pixiv_series_smoke.cjs`(생성·종류 제한·이전/다음 화·뷰어 끝 카드·편집 순서·비밀글·타 회원 차단·삭제 정리)와 기존 `tests/pixiv_board_smoke.cjs`로 확인했습니다. 사용자 실서버와 모든 모바일 기종에서 실행한 것은 아닙니다.
