# ucho_menu 호환 작업과 에디터 줄바꿈 수정

사용자가 제공한 `ucho_menu.zip`을 `AvocadoEdition_Light/skin/menu/ucho_menu`에 이식했습니다. 원본의 아이콘·드롭다운 형태를 유지합니다.

- 외부 제작자 서버의 CSS와 고정된 `more/setup.php` 경로를 로컬 스킨 경로로 바꿨습니다.
- 메뉴는 한 번 조회하고 부모/자식 연결을 두 단계로 처리하여 조회 순서에 따른 누락을 방지합니다. 정수인 `me_order`의 불필요한 산술 정렬을 없앴습니다.
- CSS를 스킨 범위로 제한하고, 페이지 전체 이미지의 클릭을 막던 규칙을 제거했습니다. 모바일과 키보드 펼치기·Escape 닫기를 지원합니다.
- 메뉴 코드 설정은 최고관리자와 세션 토큰을 확인합니다. 전체 코드와 부모 존재·중복을 검증한 뒤 한 SQL문으로 저장합니다. 메뉴명·링크는 출력 시 검증·이스케이프합니다.

디자인 관리에서 메뉴 스킨을 `ucho_menu`로 선택합니다. 원본처럼 2자리 대메뉴, 4자리 하위 메뉴를 사용합니다. 이름과 링크 편집은 기존 메뉴 관리에서, 코드 배치는 이 스킨의 메뉴 구조 설정에서 합니다. DB 필드 추가나 데이터 초기화는 하지 않습니다.

## 줄바꿈 원인

실제 키보드 입력으로 Enter 두 번과 Shift+Enter를 검사했습니다. 에디터의 `<p></p>`와 `<br>`는 저장되어 있었지만, 사이트의 문단 초기화 스타일 때문에 빈 문단 높이가 0이 됐습니다. `css/editor-content.css`를 조회 본문에 적용해 빈 문단 한 줄 높이를 유지합니다. 저장된 게시글을 일괄 변환하지 않습니다.

## 검증

PHP 8.4 구문 검사, `tests/ucho_menu_test.php`, 실제 브라우저의 메뉴 PC·모바일 조작과 설정 접근·위조 요청 차단을 확인했습니다. 픽시브와 기본 게시판에서 실제 입력→저장→조회 및 수정 화면을 비교했습니다. 외부 호스팅의 개별 CSS 수정은 검증 범위에 포함되지 않습니다.
