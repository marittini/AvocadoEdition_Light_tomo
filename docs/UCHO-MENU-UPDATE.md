# ucho_menu 호환 작업과 에디터 줄바꿈 수정

사용자가 제공한 `ucho_menu.zip`을 `AvocadoEdition_Light/skin/menu/ucho_menu`에 이식했습니다. 원본의 아이콘·드롭다운 형태를 유지합니다.

- 외부 제작자 서버의 CSS와 고정된 `more/setup.php` 경로를 로컬 스킨 경로로 바꿨습니다.
- 메뉴는 한 번 조회하고 부모/자식 연결을 두 단계로 처리하여 조회 순서에 따른 누락을 방지합니다. 정수인 `me_order`의 불필요한 산술 정렬을 없앴습니다.
- CSS를 스킨 범위로 제한하고, 페이지 전체 이미지의 클릭을 막던 규칙을 제거했습니다. 모바일과 키보드 펼치기·Escape 닫기를 지원합니다.
- 메뉴 코드 설정은 최고관리자와 세션 토큰을 확인합니다. 전체 코드와 부모 존재·중복을 검증한 뒤 한 SQL문으로 저장합니다. 메뉴명·링크는 출력 시 검증·이스케이프합니다.

디자인 관리에서 메뉴 스킨을 `ucho_menu`로 선택합니다. 원본처럼 2자리 대메뉴, 4자리 하위 메뉴를 사용합니다. 이름과 링크 편집은 기존 메뉴 관리에서, 코드 배치는 이 스킨의 메뉴 구조 설정에서 합니다. DB 필드 추가나 데이터 초기화는 하지 않습니다.

## 줄바꿈 원인

실제 키보드 입력으로 Enter 두 번과 Shift+Enter를 검사했습니다. 에디터의 `<p></p>`와 `<br>`는 저장되어 있었지만, 사이트의 문단 초기화 스타일 때문에 빈 문단 높이가 0이 됐습니다. `css/editor-content.css`를 조회 본문에 적용해 빈 문단 한 줄 높이를 유지합니다. 저장된 게시글을 일괄 변환하지 않습니다.

## 검증

PHP 8.4 구문 검사, `tests/ucho_menu_test.php`, 실제 브라우저의 메뉴 PC·모바일 조작과 설정 접근·위조 요청 차단을 확인했습니다. 픽시브와 기본 게시판에서 실제 입력→저장→조회 및 수정 화면을 비교했습니다. 외부 호스팅의 개별 CSS 수정은 검증 범위에 포함되지 않습니다.

## BGM 재생 지원

ucho_menu는 basic과 달리 BGM 버튼을 출력하지 않았습니다. 원인은 두 가지였습니다.

1. 이식된 `menu.L.inc.php`(T/R/B도 이 파일을 사용)에 basic의 BGM 블록(`bgm_frame` 재생 프레임과 켜기/끄기 버튼)이 없었습니다.
2. 메뉴 전체가 정적 클로저 안에서 출력되어 전역 `$config`를 읽지 못했습니다. 블록만 복사해도 `cf_bgm`이 비어 보여 출력되지 않습니다.

`$config`를 클로저에서 읽도록 하고 basic과 같은 조건(메인 `index.php` + 환경설정의 BGM 재생목록)·같은 프레임 이름·같은 `fn_control_bgm()` 전환을 사용하는 BGM 항목을 메뉴 끝에 추가했습니다. BGM 항목의 마크업·아이콘(`music_note`/`music_off`)·툴팁 문구(BGM OFF/ON)는 basic에서 그대로 가져왔습니다.

툴팁(아이콘 이름과 BGM ON/OFF)은 ucho_menu CSS가 글꼴(sans-serif)·색(#666)·크기(11px)·배경·테두리를 `!important`로 고정해 디자인 설정의 ‘메뉴 툴팁’ 값을 무시하고 있었습니다. 고정값을 지우고 디자인 설정을 그대로 따르게 했습니다. 위치는 메뉴 배치(좌·우·상·하)와 관계없이 하위 메뉴처럼 아이콘 바로 아래 가운데에 표시합니다. 하위 메뉴 드롭다운의 모양은 바꾸지 않았습니다. 브라우저 자동재생 정책은 basic과 동일하게 적용됩니다.

로컬 테스트 사이트에서 메뉴 좌측·상단 배치 모두 툴팁의 글꼴·색·크기가 디자인 설정값과 같고 아이콘 중앙 아래에 표시되는 것을 측정했고([캡처](screenshots/ucho-bgm-tooltip.png)), ucho_menu와 basic을 번갈아 선택해 재생 프레임 로드, 끄기→켜기 전환, 버튼 표시가 같게 동작하는 것을 확인했습니다(YouTube 실제 재생은 외부 접속을 막은 환경이라 프레임 주소까지만 확인).

## 하위 메뉴 자동 닫힘 · 말풍선 이름표 (추가 수정)

- PC에서 아이콘을 눌러 하위 메뉴를 연 뒤(특히 BGM이 켜진 첫 화면) 마우스를 떼도 메뉴가 남아 있던 문제를 고쳤습니다.
  누른 버튼에 남은 포커스가 메뉴를 붙잡고 있었기 때문입니다. 이제 마우스를 떼거나, 하위 메뉴 링크를 누르거나,
  바깥(본문 창 포함)을 누르면 닫힙니다. 키보드로 옮겨 오면 그대로 열립니다.
- 하위 메뉴가 없는 아이콘(홈, 로그인, 로그아웃, 관리자 등)의 이름표도 하위 메뉴처럼 꼬리 달린 말풍선으로 나옵니다.
  색 · 글꼴 · 크기 · 모서리는 여전히 디자인 설정의 ‘메뉴 툴팁’을 따르고, 꼬리는 같은 배경색을 씁니다.
- 테스트: `tests/ucho_menu_smoke.cjs` (임시 메뉴를 만들어 확인한 뒤 지우고, 메뉴 스킨 설정을 되돌립니다).
